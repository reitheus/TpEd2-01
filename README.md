# Tp-01_ed2
Trabalho pratico de estrutura de dados 2/ 22.2
Para realizar esse estudo, serão implementados os métodos de pesquisa externa mencionados acima em um ambiente de memória externa. Serão analisadas a complexidade de desempenho de cada método, levando em consideração fatores como tempo de acesso, número de operações de leitura/gravação e utilização de recursos de memória.

Além disso, serão realizados experimentos práticos para comparar o desempenho dos métodos em diferentes cenários, como tamanho do conjunto de dados e distribuição dos elementos. Os resultados obtidos serão analisados e discutidos, permitindo uma avaliação mais precisa das vantagens e desvantagens de cada método de pesquisa externa.

Ao final do trabalho, espera-se obter uma compreensão mais aprofundada da complexidade de desempenho dos métodos de pesquisa externa estudados, bem como suas aplicações e limitações. Isso contribuirá para o avanço do conhecimento na área de estrutura de dados e auxiliará no desenvolvimento de soluções eficientes para problemas que envolvam grandes volumes de dados armazenados em memória externa.

O projeto será desenvolvido na disciplina de Estrutura de Dados 2, no semestre 22.2. O objetivo principal é aplicar os conceitos aprendidos em sala de aula e aprofundar o conhecimento sobre métodos de pesquisa externa. O trabalho prático será realizado em equipe, promovendo a colaboração e o compartilhamento de ideias entre os membros.
